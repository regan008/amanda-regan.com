Getting Started with Palladio for Network Analysis

March 12, 2019 Amanda E. Regan 8 min read

I came to Palladio the way most digital humanists do — through desperation. I had a spreadsheet of several thousand connections, no idea how to visualize them, and a chapter deadline that was not going to move itself.

Palladio is a browser-based visualization tool built by the Stanford Humanities + Design Lab. Unlike most network tools, it requires no installation and no coding — you paste in a spreadsheet and it starts drawing connections. That simplicity is both its greatest strength and its defining constraint.

For historians, the important thing to understand upfront is that Palladio works from tabular data. Your evidence needs to be structured as rows of relationships before the tool can do anything useful with it. If you're working from archival documents, that structuring work — deciding what counts as a connection, what the nodes should be — is where the real intellectual labor lives.

Preparing Your Data

Palladio expects a CSV where each row represents a relationship. At minimum you need two columns — a source node and a target node. I added a third column for relationship type, which let me filter the network once it was built.

The structuring question — what counts as a connection? — is not a technical problem. It's a historical argument disguised as a data problem.

Field notes, Oct. 2018

Once your CSV is clean, upload it directly in the Palladio interface. The tool auto-detects column types — watch for false positives on date columns, which it sometimes misreads as geographic coordinates.

Building the Network View

In the Network tab, set your Source and Target dimensions. Palladio will render a force-directed graph automatically. The layout is not deterministic — it shifts every time — so don't read too much into the spatial positions of nodes. What matters is degree (how many connections a node has) and clustering.

To highlight high-degree nodes, use the Size nodes by dimension option and map it to a count field. I computed this beforehand in Python with a one-liner: 

df['degree'] = df.groupby('source')['target'].transform('count')

Add the degree column to your CSV before uploading. Palladio will then let you scale node size by it, making the most connected actors immediately visible in the graph.

A Note on Export

Palladio's export options are limited. You can save the graph as an SVG, which is useful for publication figures, but the tool doesn't save your session state natively. I got into the habit of exporting the gallery view as an image after every work session as a cheap form of version control.

For a more durable workflow, take a look at Gephi once you've outgrown Palladio's simplicity. The learning curve is steeper, but the layout algorithms and filtering options are considerably more powerful — and it actually saves project files.
